Guidelines

Workflow Setup
  • Name: Use descriptive names for easy identification
  • Steps: Add steps in sequential order
  • Roles: Assign appropriate roles for each step
  • Approvals: Set minimum required approvals per step
Tip: There can be only one active workflow per action type.
Best Practices

When creating workflows:

  1. Keep step orders sequential (1, 2, 3...)
  2. Assign roles based on organizational hierarchy
  3. Set realistic approval requirements
  4. Test thoroughly before activation
